# tools/decrypted/upstream_status.py reads it. A commit we cherry-picked needs no line: the script

#
#   <commit> <status> [note]   | subject (for reading only)
#
#   ported  ported by hand; the note is our commit
#   have    already in our tree through ctr-native or dowlle
#   own     we have our own version of it; the note says where
#   planned on the ROADMAP Planned list; the note says which item
#   maybe   on the ROADMAP Maybe list; the note says which item
#   skip    not wanted; the note says why (Vita, web, AdHoc, leaderboard, docs...)
