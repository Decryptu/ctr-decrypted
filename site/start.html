New to Archipelago? Read this firstOne minute, and every word the checklist uses.

Archipelago is a randomizer that links games together. In a normal randomizer, the things you unlock (in CTR: trophies, keys, gems, relics, racers) are shuffled around your own game. In Archipelago, they are shuffled across several games played by several people at once. Winning a race in your CTR may unlock a sword in a friend's Zelda, and their dungeon may hold your next boss key. You help each other progress.

CTR Decrypted is the game with that link built in: no emulator, no patching, no separate client program. Every game in the session runs through these five stages:

  1. OptionsEach player writes a small settings file, a YAML.
  2. GenerateThe host feeds every YAML to Archipelago, which shuffles the items into one seed.
  3. HostThe seed runs on a server room, on archipelago.gg or a home PC.
  4. ConnectEveryone points their game at the room with their slot name.
  5. PlayFinish events to send items; receive the ones others find for you.

Playing alone? The Play Solo mode does stages 2 to 4 for you, inside the game.

Words you will meet

Multiworld
One shared Archipelago session. Each player's game in it is a "world".
YAML
Your options file (a .yaml text file): your player name, the game, and how it is randomized. Make it with the YAML builder.
Slot
Your place in the room. Its name is the name in your YAML, and you must type it exactly, capitals included, to connect.
APWorld
The ctr.apworld file that teaches Archipelago about CTR. Only the person generating needs it.
Seed
One generated shuffle: the AP_….zip Archipelago makes from everyone's YAML.
Room
The server running a seed. Players connect to it with its address, like archipelago.gg:38281.
Location / check
Something you do that sends an item: winning a Trophy race, a relic time trial, a CTR token, breaking an AP item box.
Item
What a location holds: a key, a trophy, a racer, a kart upgrade, a trap. It can belong to you or to another player.
Logic
The rules that make sure every seed can be finished: an item you need is never locked behind itself.
Sync / async
Sync: everyone starts together at a countdown. Async: people play whenever they like over days or weeks.
Hint
Asking the server where one of your items is. It costs hint points you earn by checking locations.
Release / collect
Release sends every item still in your world to its owner; collect takes all of yours at once. Used when someone finishes or leaves.
DeathLink
An optional link: when one linked player fails, everyone linked fails too. Off in CTR unless you turn it on.

Step 1
Finish!

Every step is done. Have a great run.

  1. Download the game

    Download for Windows

    Right-click the .zip, choose Extract All, and extract it into a folder of its own, for example Documents\CTR Decrypted. Do not run the game from inside the zip, and avoid Program Files: the game writes its settings and saves next to itself.

    Download for Linux

    Extract it into a folder of its own, for example ~/Games/CTR:

    mkdir -p ~/Games/CTR && tar -xzf ctr-decrypted-*-linux-x86.tar.gz -C ~/Games/CTR

    The game is a 32-bit program. If it starts with no sound, see Troubleshooting; Linux and Steam Deck lists what it needs.

    Switch to Desktop Mode (Steam button, Power, Switch to Desktop) and open this page in the browser there.

    Download for Steam Deck

    Open the downloaded .tar.gz in the Dolphin file manager and extract it into a folder of its own, for example Games/CTR in your home folder.

    You only do this once. From then on the game updates itself: the main menu offers each new version, and your settings and saves stay.

  2. Check your disc image

    The game reads your .bin directly: no extracting, no Python. It must be:

    • the North American release (boot id SCUS_944.26). European and Japanese discs are recognised and refused;
    • a raw image (MODE2/2352), as disc-dumping tools make by default. A .iso, even renamed to .bin, lacks the music and video data and will not work.

    The file name does not matter, and the .cue is not needed.

  3. Turn your .chd into a .bin

    The game reads raw .bin images, so unpack the .chd once with chdman, which comes with the MAME tools (on Linux, often in a mame-tools package):

    chdman extractcd -i "CTR.chd" -o "CTR.cue" -ob "CTR.bin"

    Keep CTR.bin and use it in the next step. It must be the North American release (SCUS_944.26).

    Prefer to keep only the game's files? The extractor in the setup guide's appendix reads a .chd directly (it needs Python and chdman).

  4. Make an image of your disc

    Put the disc in a PC CD or DVD drive and copy it with a disc-dumping program that saves PlayStation discs as BIN/CUE in raw mode (MODE2/2352), the same format PlayStation emulators use.

    • Choose BIN/CUE, never ISO: an ISO drops the music and video tracks.
    • Only the North American disc works (the label on the case says NTSC U/C; the boot id is SCUS_944.26).

    You end up with a .bin (and a .cue). The game needs only the .bin.

  5. First launch: give the game your disc

    Still in Desktop Mode, open the game folder, create a folder named assets and copy your .bin into it:

    CTR/
  ctr_native_ap
  assets/
    ctr-u.bin

    Then right-click ctr_native_ap and choose Add to Steam. Go back to Gaming Mode and start ctr_native_ap from your library (under Non-Steam). The first start on a Deck is fullscreen at 16:10, with the built-in controls as the controller.

    Start ctr_native_ap.exe./ctr_native_ap. The first time, it searches the game folder, your Downloads, Desktop, Documents and Games folders for your disc. If it finds it, it asks whether to use it; if not, a file picker opens. It then offers to copy the image into the game folder, or to remember where it is.

    Or put it in place yourself: an assets folder next to the game, holding the .bin under any name.

    A short setup screen then opens on the title screen. Its first page asks for your room: keep it open for the connect step.Its first page asks for an Archipelago room: you can skip it. The next pages pick fullscreen, aspect ratio, render scale, 60 FPS, skipping the intros and Discord status. Everything there can be changed later in OPTIONS.

  6. Make your and send it to the host

    1. Open the YAML builder.
    2. Type a player name: it becomes your name. It must be unique in the room, at most 16 characters, and you will type it again later with the same capitals.
    3. For a first game, leave the options at their defaults or pick a preset. Read an option's help to see what it does.
    4. Press Download YAML and send the file to the host the way they asked (a Discord message, a collection website).

    The builder always matches the newest release. If the host generates with an older version, ask them which one, and use that release's game too: the game, the YAML and the host's must come from the same release.

  7. Wait for the room

    The host generates the once everyone has sent a YAML, starts the , and shares its details. Meanwhile, try a race to check your controller and settings.

  8. Get the room details

    You need three things, usually from the room page the host links:

    • Server address with its port, like archipelago.gg:38281. The room page's own web link (archipelago.gg/room/…) is not the address: look for the line with the port number.
    • Your slot name: the name in your YAML, exactly, capitals included.
    • The password, if the room has one.

    An archipelago.gg room goes to sleep when nobody plays. Opening its page wakes it up, and the port can change: copy the address from the page again if connecting stops working.

  9. Install Archipelago

    Archipelago is the program that generates seeds and runs rooms. Get the newest release from its official releases page: the Windows installer (Setup.Archipelago…exe), or the Linux AppImage or archive. It installs the Archipelago Launcher, which has everything you need: Generate, Host, Install APWorld.

    On Windows it installs into C:\ProgramData\Archipelago by default. The Launcher's Browse Files opens that folder wherever it is.

  10. Add CTR to Archipelago

    Archipelago does not know CTR until you give it the :

    Download ctr.apworld

    Double-click it, or use Install APWorld in the Launcher, or copy it into the custom_worlds folder of your Archipelago install. Then close and reopen the Launcher.

    Only the person generating needs the APWorld. Use the one from the same release as everyone's game, and tell your players which release that is.

  11. Collect everyone's YAML

    Send your players this page with Join a room picked: start.html#join. Each player makes a YAML with the YAML builder and sends it to you. Make one for yourself too if you play.

    • One YAML per , and every slot name different, even when one person plays two games.
    • Players of other games make their YAML for their game. A game that is not built into Archipelago needs its APWorld installed on your side as well.
    • Agree on the dates and rules first: when YAMLs are due, , hint rules.

  12. Generate the seed

    1. Put every YAML in the Players folder of your Archipelago install (C:\ProgramData\Archipelago\Players on Windows). Remove files left over from earlier games, and unzip YAMLs that came in a zip.
    2. In the Launcher, click Generate.
    3. When it finishes, the output folder holds a file named like AP_12345678901234567890.zip: that is the whole . Do not unzip it.

    Generate on your own computer. The generator and YAML checker on the archipelago.gg website do not include CTR, so they reject a CTR YAML.

    If generation fails, the error names the YAML or option at fault. Ask that player for a corrected file rather than editing their options yourself.

  13. Open the room on archipelago.gg

    1. Go to archipelago.gg/uploads and upload the AP_….zip.
    2. The upload makes a seed page (with the spoiler log). Click Create New Room to start the server.
    3. The room page shows the address with its port (archipelago.gg:port), every slot, a tracker, and a console for host commands.

    The room sleeps when nobody is connected, and wakes when someone opens its page. Its port can change then, so players should copy the address from the page.

  14. Run the room on your computer

    1. In the Launcher, click Host and pick the AP_….zip (no need to unzip it).
    2. A console window opens. When it prints Hosting game at …, the room is up. Keep that window open for the whole game.

    The port is 38281 unless you changed it. The address to give depends on where players are:

    • This computer: localhost:38281.
    • Your home network: this computer's local address, like 192.168.1.20:38281 (Windows: ipconfig; Linux: ip addr).
    • Over the internet: your public address, after forwarding TCP port 38281 on your router to this computer and allowing it through the firewall.

    0.0.0.0 in the console is not an address to give anyone. If you cannot open a port, use archipelago.gg instead.

  15. Share the room

    Send every player the room page link (it lists the address and every slot), the address with its port, their exact slot name, the password if you set one, and the checklist link: start.html#join/ready.

    While the game runs, the room's console takes commands: /help lists them. Use them to a player who leaves, or to collect for one who is done. Players can ask for a by typing !hint item name in the Archipelago Text Client (in the Launcher).

  16. Connect to the roomPlaying too? Connect to your room

    In the setup screen, or later in OPTIONS → Connection, fill in:

    • Server: the address and port. For a room on this same computer, localhost:38281.
    • Slot: your slot name.
    • Password: leave it empty if there is none.

    Select Connect (in the setup, Next connects too) and watch the status line until it says Connected. The game saves these settings and reconnects by itself next time.

    Selecting a field opens the Steam on-screen keyboard. X or START saves the field, TRIANGLE cancels it.

    Error? InvalidSlot means the slot name does not match: check the capitals. See Troubleshooting for the rest.

  17. Race!

    Go back to the main menu and start Adventure. In a game, wait for the host's countdown before your first race.

    • Win a race, a relic, a token or a cup and continue past its results screen: that sends its .
    • Items you receive, and the ones you send, show in the feed during races and in the hub. Keys and trophies open warp pads and doors; traps arm quietly and fire in a later race.
    • Save at the hub's save station as usual. The server remembers your items and checks: if the connection drops, the game keeps what you did and sends it when it reconnects.

    A red SEED NOT COMPLETABLE on the hub means the seed is broken: stop and report it (see Stuck? below).

  18. Open Play Solo

    On the title screen, choose PLAY SOLO (it is also in OPTIONS → Connection → Play Solo). The game generates and hosts your seed itself, on a private server on your own computer: no Archipelago install, no account, no internet.

  19. Make a seed

    Choose New solo seed, then a preset:

    • Quick: a shorter seed with few locks, ending when you beat Oxide. Good for a first try.
    • Standard: the default options.
    • Full Adventure: everything on, with Oxide's Final Challenge as the goal.

    The next screen shows the preset's main options: Left and Right change one, Square explains it. For every option, make a YAML in the YAML builder and choose Import YAML file (or drop it in the solo/inbox folder next to the game).

  20. Race!

    The game starts the seed and drops you in Adventure. Win races, relics, tokens and cups to find your items; keys and trophies open warp pads and doors.

    To continue later, open PLAY SOLO again: your seeds are listed with their progress, and Cross resumes one. They live in the solo folder next to the game, and OPTIONS → Backups keeps earlier copies.

  21. Race!

    Skip the room page of the setup screen and play: Arcade, Time Trial, VS and Battle, with 60 FPS, widescreen and 200cc (on the SPEED screen of Arcade and VS).

  22. Optional: new tracks and racers

    Choose MODS on the title screen. L1 and R1 switch tabs: Tracks lists community tracks to install with Cross, Racers lists custom characters. Installed tracks show on extra pages of the Arcade and Time Trial track lists (press Right past the last page). See Custom tracks and Custom racers.

  23. Optional: make it look and feel right

    • OPTIONS → Video: 60 FPS, widescreen, render scale, PGXP (no wobbly polygons), screen filters and draw distance.
    • OPTIONS → Controls: pick a controller, rebind buttons, set a stick deadzone (Controls).
    • OPTIONS → Extras: the reserves meter, blue fire, colour filters and other small additions (Extras).
Progress is kept in this browser only.

Stuck?

  • Slot not found: copy the slot name exactly, capitals included.
  • Missing or incomplete assets: the assets folder holds no usable North American raw .bin.
  • No music, black intro: the image is a cooked .iso. Re-dump it as BIN/CUE.
  • Cannot connect: recopy the address and port from the room page.

More in Troubleshooting.

Report a problem

Run support-bundle.bat (Windows) or ./support-bundle.sh (Linux, Steam Deck) in the game folder. It packs your logs, password removed and no game data, into one archive.

Attach it to a GitHub issue with a line about what happened. For a broken seed, add your YAML and the spoiler log.
