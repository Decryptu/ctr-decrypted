# The CTR world fuzz arms (.github/workflows/apworld.yml, fuzz job).
#
# Columns: name, generations in the full run, generations on a push or pull
# request (0: the full run only), meta, hook. The full run is every arm at its
# full count: nightly on dev, and by hand (Run workflow) for a release. A push
# runs about twenty arms that cover each family at a few hundred seeds, so it
# fits in one wave of runners.
#
# meta: "canonical" is the index's canonical generation check; "random" is
# random-meta.yaml; "accessibility-full" is random-meta.yaml with accessibility
# full; gem-cups-<count>-<tracks> fills content-plan-gem-cups-meta.yaml;
# pads-<unlock>-<placement>-<density>[-<fixed>[-<overlay>]] fills
# content-plan-pads-meta.yaml (<fixed>: keys, gems, both, filler, all or none;
# <overlay>: a file in overlays/); any other name is <meta>-meta.yaml.
# hook: a fuzz hook, "-" for none. hooks.ctr_ut_hook:Hook also installs
# Universal Tracker and compares its logic with the server's (ctr_ut_hook.py).
